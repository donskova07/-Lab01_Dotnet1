# ответы на вопросы 

1.
Console.Write() выводит текст в консоль, но не добавляет символ перевода строки — последующий вывод продолжится в той же строке. А Console.WriteLine() после вывода текста добавляет перевод строки, и следующий вывод начнётся с новой строки. 

2.
Возникнет ошибка компиляции. Тип int предназначен для целых чисел, а 3.14 — это число с плавающей точкой (по умолчанию имеет тип double). Компилятор не может неявно преобразовать double в int, так как при этом теряется дробная часть. 

3.
В C# при делении двух целых чисел (int / int) результат тоже будет целым — дробная часть отбрасывается (происходит целочисленное деление). Чтобы получить дробный результат, нужно хотя бы одно из чисел явно привести к типу с плавающей точкой (например, double). Например: 10.0 / 3 или 10 / 3.0. 

4.
Ключевое слово var в C# позволяет компилятору самому вывести тип переменной на основе присвоенного значения (это называется неявной типизацией). При этом тип фиксируется на этапе компиляции и не меняется во время выполнения — это статическая типизация. В Python же используется динамическая типизация: тип переменной определяется во время выполнения программы и может меняться по ходу работы.
